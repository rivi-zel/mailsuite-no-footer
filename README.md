# Mailsuite - No Footer

Mailsuite 12.96.1 for Chrome, repackaged without the promotional footer and unsubscribe link.

Nothing in the original tracking was touched - every open is still recorded through Mailsuite's own servers, so the service works exactly as before and Mailsuite keeps getting all of it. The only change is cosmetic: the footer promo is hidden.

## Install
1. Download the latest release ZIP and extract it.
2. Remove the store version of Mailsuite to avoid conflicts.
3. Open chrome://extensions, enable Developer mode.
4. Load unpacked, choose the extracted folder.

## Updates
The extension checks this repo once a day and notifies you in Chrome when a new version is out - it reminds you daily until you install it. Updates install manually from the Releases page.
